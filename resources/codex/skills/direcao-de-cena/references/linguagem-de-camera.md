# Linguagem de Câmera → Emoção

Referência profissional de como cada escolha de câmera comunica emoção. Use no Passo 4 (cobertura) do pré-plano para justificar cada plano.

## O princípio central

Em produção profissional, nenhuma escolha de câmera é aleatória. Cada plano, ângulo e movimento comunica algo ao subconsciente do público. O diretor escolhe a câmera que serve o beat emocional.

## Tipos de plano → o que comunicam

| Plano | Comunica | Beat ideal |
|-------|----------|------------|
| Plano geral extremo | Pequenez, contexto, solidão | Personagem diante de algo maior |
| Plano geral | Ação, espaço, situação completa | Movimento, chegada |
| Plano médio | Neutralidade, observação | Diálogo, ação cotidiana |
| Primeiro plano | Intimidade, emoção, atenção | Momento emocional, reação |
| Plano detalhe | Tensão, importância, foco absoluto | Decisão, objeto-chave |
| POV | Imersão, "estou na pele dele" | Suspense, descoberta |
| Sobre o ombro | Conexão, perspectiva, relação | Diálogo, confronto |

## Ângulos → o que comunicam

| Ângulo | Comunica | Beat ideal |
|--------|----------|------------|
| Nível dos olhos | Neutralidade, igualdade | Padrão, 60-70% dos planos |
| Câmera baixa | Poder, heroísmo, ameaça | Herói se firmando, vilão dominando |
| Câmera alta | Fragilidade, derrota, pequenez | Personagem perdido, vulnerável |
| Vista aérea | Onisciência, geografia, destino | Estabelecer, momento de virada |
| Câmera inclinada | Caos, erro, instabilidade | Algo errado, vilania, confusão |

## Movimentos → o que comunicam

| Movimento | Comunica | Beat ideal |
|-----------|----------|------------|
| Estático | Estabilidade, calma, controle | 60-70% dos planos, diálogo |
| Push-in (aproxima) | Intimidade crescente, foco, tensão | Momento emocional intensificando |
| Pull-back (afasta) | Revelação, isolamento, conclusão | Fim de cena, revelar contexto |
| Pan | Acompanhar, conectar espaços | Seguir movimento lateral |
| Tilt | Revelar verticalmente, escala | Mostrar algo alto/baixo |
| Tracking | Energia, acompanhamento | Personagem em movimento |

## Composição → o que comunica

| Técnica | Efeito |
|---------|--------|
| Personagem no centro | Importância, simetria, estabilidade |
| Regra dos terços | Equilíbrio natural, dinamismo |
| Personagem pequeno no quadro | Solidão, vulnerabilidade |
| Personagem dominando o quadro | Poder, proximidade |
| Espaço de respiro (lead room) | Pra onde o personagem olha/vai |
| Enquadramento apertado | Tensão, claustrofobia |

## Distância emocional = distância física

Regra de ouro: a proximidade da câmera espelha a proximidade emocional.

- Quer o público próximo do personagem? Close.
- Quer distância emocional? Plano geral.
- Quer crescer a conexão? Comece longe, aproxime ao longo da cena.

## Combinações que contam história

A mágica está em combinar plano + ângulo + movimento para um efeito específico:

| Objetivo | Combinação |
|----------|------------|
| Entrada heroica | Plano geral + câmera baixa + tilt-up |
| Momento de decisão | Plano detalhe (olhos) + estático + leve push-in |
| Personagem derrotado | Plano geral + câmera alta + estático |
| Vilão intimidador | Plano médio + câmera baixa + push-in lento |
| Revelação de mundo | Plano geral extremo + vista aérea + pull-back |
| Conexão entre dois | Sobre o ombro + nível dos olhos + estático |
| Tensão crescente | Sequência: médio → primeiro plano → detalhe (fechando) |

## Progressão dentro de uma cena

Cenas profissionais raramente ficam num plano só. A progressão típica:

```
ABERTURA: estabelece (geral, neutro)
   ↓
DESENVOLVIMENTO: aproxima conforme a emoção cresce (médio → close)
   ↓
CLÍMAX: o plano mais fechado/dramático do beat de pico
   ↓
RESOLUÇÃO: afasta pra fechar (pull-back, geral)
```

## Gramática de diálogo (shot/reverse shot)

Para conversas e confrontos entre dois personagens:

1. **Estabelecedor:** plano que mostra os dois e o espaço
2. **Shot:** plano do personagem A falando (often sobre o ombro de B)
3. **Reverse shot:** plano de B respondendo (sobre o ombro de A)
4. Alterna entre os dois conforme a conversa

**Regra dos 180°:** trace uma linha imaginária entre os dois personagens. Mantenha TODAS as câmeras de um lado dessa linha. Cruzar a linha faz parecer que os personagens trocaram de lugar — desorienta o público.

## Erros profissionais a evitar

- Trocar de plano sem mudar ângulo ou distância em 30°+ (jump cut, parece erro)
- Movimento de câmera sem motivo (câmera só se move quando serve algo)
- Câmera dramática em momento neutro (gasta o impacto)
- Ângulo inclinado em excesso (enjoa, perde o efeito)
- Esquecer a regra dos 180° em diálogo (desorienta)
- Plano único pra cena inteira (estático, amador)

## Aplicação no pré-plano

No Passo 4 (cobertura), para cada plano, use estas tabelas para:
1. Escolher o plano + ângulo + movimento que serve o beat
2. Escrever o "propósito" justificando a escolha emocionalmente

Exemplo de propósito bem escrito:
> "Plano detalhe nos olhos + push-in lento: isola o momento de decisão do Tito, o público sente o peso da escolha. A aproximação da câmera espelha a intensificação interna."

Isso é direção profissional — cada câmera com intenção emocional clara.
